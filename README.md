# 三国杀 · 单机身份局

纯 HTML / CSS / JavaScript，本地运行，无后端、账号或在线素材依赖。

## 启动

直接打开 `index.html`，或使用 Node.js：

```sh
npm start
```

浏览器访问 http://127.0.0.1:8765 。如果已有旧页面，请刷新。

## 操作

1. 选择人数、难度、速度，开始并选将。
2. 点手牌或金色技能按钮；转化技能会提示需要选几张牌。
3. 点高亮目标，再按「确定」。多目标技能可以依次选择目标。
4. 需要装备作为代价时，点自己武将旁的装备名称；选中后有金色描边。
5. 鼠标停留在卡牌、技能或装备上可查看完整说明。

灰色立绘表示翻面；蓝色描边表示横置。田、不屈、化身等状态显示在角色旁。主公技仅在相应身份有效；黄天献牌、制霸拼点入口显示在满足条件的其他角色的出牌阶段。

## 验证

```sh
npm test
npm install
# 另开终端运行 npm start；浏览器测试使用本机 Microsoft Edge
npm run test:browser
node tests/battle-ui.cjs
node tests/junzheng-ui.cjs
```

引擎测试涵盖技能注册、核心规则回归、武将联动、自动对局以及实体牌数量守恒。浏览器测试覆盖卡包筛选/搜索、主动技能、丈八蛇矛、装备转化和页面错误；截图输出到 `tests/artifacts/`。测试覆盖的是列出的场景，并非穷举所有技能组合。

## 文件

- `js/core/game.js`：对局流程、牌结算。
- `js/core/skills.js`：原有武将技能和视为牌。
- `js/core/expansion.js`：扩展武将、事件、状态与扩展 AI 策略。
- `js/ai/ai.js`：身份推理、出牌及响应。
- `js/ui/ui.js`、`css/readability.css`：交互与可读性。
- `assets/art/`：生成的本地插画图集；`assets/manifest.js` 指定对应区域。

插图为本项目生成的新素材，并非官方卡图。少数标准坐骑共用同类画面。修改贴图时可在素材清单中将任意图集配置替换为单张图片路径。

军争牌表核对：[军争篇卡牌](https://wiki.biligame.com/sgs/军争篇卡牌)；装备规则核对：[装备牌规则](https://gltjk.com/sanguosha/rules/card/equipment.html)。军争新增锦囊现已使用独立插图。`junzheng-ui.cjs` 覆盖 5 种窗口尺寸、八人满装备与判定牌场景，截图输出至 `tests/artifacts/`。
