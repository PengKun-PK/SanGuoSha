# 一将成名与八神将

本次按用户指定的 63 人名单接入经典身份局技能。华雄复用原有角色 ID，改归一将成名 2012，使用「恃勇」；因此净新增 62 个角色，武将库 119 人，其中于吉仍停用，可选 118 人。

每年 11 人，神·风、火、林、山各 2 人。2015 的郭皇后、公孙瓒按用户指定分组，不代表官方发行归属。郭皇后使用经典「矫诏／殚心」，公孙瓒使用「义从／趫猛」。神将在开局选择魏、蜀、吴、群之一参与势力规则。

## 规则基线

采用一套固定的经典身份局规则，避免在线、移动版、界限突破和国战同名技能混用。具体文字以游戏选将页和技能说明为准。尤其注意这些存在多个版本的技能：

| 技能 | 本项目使用的版本 |
| --- | --- |
| 毅重 | 无防具时黑色杀无效 |
| 伤逝 | 手牌补至已损失体力，至多 2 |
| 破军 | 杀造成伤害后令目标摸当前体力数的牌（至多 5），然后翻面；不是暂时移除手牌版本 |
| 潜袭 | 准备阶段判定，限制邻近角色对应颜色手牌 |
| 父魂 | 两张手牌当杀，造成伤害后获得本回合武圣、咆哮 |
| 仁心 | 其他角色体力为 1 受到伤害时，弃装备并翻面以防止伤害 |
| 胆守 | 递增弃牌代价的四档效果；不是立即结束回合版本 |
| 明鉴 | 全部手牌交给另一角色，其下回合手牌上限和杀次数各 +1 |
| 燕语 | 夏侯氏重铸杀，至少两次则阶段结束令男性摸两张 |
| 殚心 | 摸一张或升级矫诏，最多升级两次 |
| 绝境／龙魂 | 神赵云摸牌加成、手牌上限 +2；龙魂代价等于当前体力且至少 1 |
| 神愤 | 每出牌阶段一次，先逐个伤害，再逐个弃装备，再逐个弃手牌 |

## 实现

- `yijiang.js`：名单、共享操作、伤害／牌流转／阶段／合法目标扩展。
- `yijiang-skills.js`：2011—2013 技能。
- `yijiang-later.js`：2014—2015 技能。
- `god.js`：八神将技能。
- `yijiang-hooks.js`：复合技能后续结算、响应转化和 AI。

阶段和回合状态使用 `flags`；觉醒、限定技消耗、暴怒、忍、梦魇和专属牌堆使用 `marks`。星、醇、逆和司敌牌存储真实卡牌，角色死亡时清理到弃牌堆。伤害与失去体力走不同路径；大雾不防止绝情或其他失去体力效果。

扩展技能支持真实玩家选择、取消和响应；AI 使用启发式选择。AI 的重复铁索重铸每回合最多三次，防止空牌堆重洗后反复抽回同一张牌；不限制真人重铸。新增武将沿用已有程序绘制的头像后备方案，未新增官方或独立写实立绘。

## 验证

`npm test` 包含原有回归、每位新增武将主要技能的确定性场景，以及多随机种子的八人对局。检查真实代价、伤害与回复、牌移动、限定／觉醒、回合效果和 160 张实体牌守恒。

`node tests/yijiang-ui.cjs` 检查每个 11 人包和四个神将包、技能搜索、龙魂两张牌转火杀、暴怒标记、主动技能、陷嗣公共出杀入口与酒诗濒死响应。`npm run test:browser` 检查原有操作和完整八人对局。

这些测试覆盖具体场景，不能视为穷举所有武将、装备和时机的组合。

2026-09-19 代码审查补充了实体牌再次使用的状态隔离、翻面回合标记清理、放权与连破的回合结束顺序、阵亡后的献图结算、华雄击杀归属、陷阵的使用／打出区别、隐藏手牌选择、濒死酒响应、矫诏属性杀、活墨属性杀共用次数和惴恐群体锦囊限制的回归测试。
